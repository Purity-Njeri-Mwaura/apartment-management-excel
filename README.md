Apartment Management & Financial Tracking System (Excel)

Project Overview
This project is an Excel-based financial and operational tracking system designed for apartment management. It organizes rental, tenant, and expense data into a structured format to support analysis of income, costs, and overall property performance.

The objective of the system is to demonstrate how structured data can be used to improve decision-making in property management. By consolidating key financial and operational records, the system enables monitoring of rent collection efficiency, arrears, occupancy trends, and monthly profitability.

The dataset is organized across multiple sheets including rent tracking, tenant records, deposits, maintenance costs, and general expenses. These are aggregated into summary views and dashboards that provide key performance indicators such as total income, total expenses, net profit, and collection rates.

This project demonstrates practical skills in data organization, financial analysis, and dashboard development using Microsoft Excel. It also reflects an understanding of how data-driven systems can improve transparency and efficiency in managing real estate operations.
